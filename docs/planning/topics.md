# 能力专题与分期交付地图

整体范围以[产品定义](../product-scope.md)为准，P1–P4 的依赖和出口沿用[工作区演进计划](writing-workspace-roadmap.md)。本页是唯一能力归属地图，不复制任务进度；当前顺位、阶段状态与未验证项见 [current](../status/current.md)，详细验收结果留在原 records。

## 层级与来源

大专题表达跨阶段能力；子专题复用既有 planning / development 文档或稳定章节；P1、P2a、P2b、P3-1–P3-4、P4-1–P4-4 是实施与整合切片。一个阶段可以涉及多条能力主线，完成某个切片不等于整条能力完成。未来插件规划保留自己的进入条件，不硬塞进 P1–P4。

任务执行状态集中维护在 current 的[分期与下一步](../status/current.md#分期与下一步)和[接下来的事项](../status/current.md#接下来的事项)；专题维护方案、任务范围和验收标准，记录保存精确版本、平台、环境与结果。路线图和索引仅引用来源，不再同步长批次流水。方案确认、实现、验收、源码发布、镜像分发与服务端部署分别判断。

## 当前接续工作的追踪方式

| current 条目                  | 牵头与任务范围                                                         | 通过标准与证据来源                                                                                                                  |
| ----------------------------- | ---------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 第 1 项：镜像分发材料         | 自托管与安全交付；实际镜像许可 / 版权、来源、源码材料和声明生成 / 校验 | [镜像分发章节](self-hosted-storage.md#镜像分发与部署编排)第 1 步；沿用 P4-4 缺口，不把清单当作许可验收                              |
| 第 2 项：Docker 分发与编排    | 自托管与安全交付；双镜像版本、拉取式 Compose、预检与受控维护           | 同章节后续步骤及原 P4 发布条件；启用、上传和部署按对应授权                                                                          |
| 第 3 项：远程治理偏差         | 横切治理维护任务，服务交付主线；不另造产品能力                         | [仓库目标设置](../governance/repository-governance.md#github-目标设置)及 current 中记录的偏差；取得授权后的远程写后读取才是关闭证据 |
| 第 4 项：真实 OIDC 与环境补验 | 服务器工作区与身份牵头；自托管协同                                     | OIDC 实施与验收及 P4 实际环境记录；保留真实发行方、物理断电和跨物理设备未验范围                                                     |
| 第 5 项：手机与公众号         | 编辑与排版体验牵头；文章资源协同                                       | [公众号判据](../deployment/wechat-acceptance.md)与 P1 / P2 原验收；桌面 / 合成结果不能代替延期证据                                  |

这些条目维持 current 原顺序、授权与延期边界。源码集成、静态站点部署、镜像分发、服务器上线和真实 OIDC 是不同交付事实。历史详情只按需读取 records；[本批记录](../records/2026-11-01-planning-alignment.md)说明本次组织调整及保留检查。
