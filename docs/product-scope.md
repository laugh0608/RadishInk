# 产品范围

RadishInk（萝卜墨笺）是基于 WeMD 的 Markdown 写作与微信公众号排版工具，定位为“专注写作，轻松排版”。

## 当前已实现范围

使用浏览器完成 Markdown 编辑、主题预览、本地草稿和公众号富文本复制。已有工作区文件读写继续维护；Web Markdown 单文件导入导出已在 `4343524` 实现，支持最新正文与元数据往返，验证边界见 [实现记录](records/2026-10-06-markdown-file-import-export.md)。Web 静态产物可以部署到 Vercel；现有 Compose 仅为前端镜像模板，不等于前后端部署已经可用。

当前代码仍有图床 / AI 入口，默认关闭，已有显式配置继续保留；用户于 2026-10-07 明确要求移除这两类功能，实施范围见 [界面专题](planning/editor-interface.md)。本轮只形成规划，不把目标写成已经实现。

## 已确认的演进方向

- 写作界面保留必要操作，文件进出集中在顶栏右侧，编辑工具按可用宽度渐进收纳。
- 以文章为资源边界：一个 Markdown 文件与 `asset/`，粘贴图片保存到当前文章；默认导出 ZIP，保留纯 Markdown 交换。
- 两种部署形态：Vercel 纯前端提供浏览器存储和受浏览器能力限制的本地文件夹；Docker Compose 提供前后端及第三种“云端（自托管服务器）”存储，并可启用账号密码隔离用户文章。

新增资源持久化、存储迁移、后端和账号均尚未实施，按 [工作区演进计划](planning/writing-workspace-roadmap.md) 分期推进。服务器存储不等于自动同步所有本地文章；首轮不提供官方托管云、计费、实时协作、离线多端同步或公共图床。关闭账号时只提供共享工作区，不能承诺用户隔离。

账号登录方式包含本地账号密码及用户补充的 [Radish OIDC 登录](planning/self-hosted-storage.md#radish-oidc-登录)，仅在有后端的部署中启用。Radish 验证外部身份，RadishInk 管理自己的用户与文章归属；不按同名 / 同邮箱自动合并账户，不复制 Radish 的业务权限或文章数据。

## 模块职责

| 目录                  | 职责与维护边界                                                                    |
| --------------------- | --------------------------------------------------------------------------------- |
| `apps/web`            | React / Vite 界面、本地存储、预览、复制和浏览器集成                               |
| `packages/core`       | Markdown 解析、主题处理、微信深色模式等共享排版逻辑                               |
| `templates`           | 主题 CSS 模板                                                                     |
| `apps/electron`       | 保留的上游桌面端；不进入当前 Web 发布基线                                         |
| `apps/server`         | 当前仍为上游图片服务，不进入 Web 发布基线；P3 评估其作为文章 / 账号后端的演进路径 |
| `scripts` / `.github` | 检查、构建、协作与远程设置模板                                                    |

Web 通过 Vite / TypeScript 别名使用 core 源码；当前 Web 构建不要求先发布 `@wemd/core`。内部包名暂时沿用上游，避免品牌修改扩散到包依赖关系。

## 验收边界

- 本地草稿按站点源和浏览器隔离，部署本身不提供云同步。
- 修改存储标识、清缓存流程或域名时考虑备份和迁移，避免用户误以为草稿丢失。
- 复制按钮成功、剪贴板含 HTML、公众号最终粘贴正确分别验收。
- 引入 AI、统计或上传服务前明确触发条件、数据去向和用户设置；不要把前端密钥当作保密后端凭据。
- 未完成的能力和未验证的平台应直接标注，不用上游宣传语代替本项目验收。
