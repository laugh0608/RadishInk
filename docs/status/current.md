## 当前产品与停止线

- Web 写作、主题预览、本地草稿 / 文件夹、Markdown 单文件进出与公众号复制的职责见 [产品范围](../product-scope.md)。本地完成不等于上线。
- 本轮浏览器升级已是产品代码，但验证只使用合成库，没有访问或迁移用户数据。下载事件不代表备份已落盘，升级需用户在界面确认保存成功。
- 升级前 JSON 仅包含旧历史文章，不含升级后的更改 / 资源；恢复到新合成库已演练，产品恢复 / 合并 UI 尚未提供。纯 Markdown 下载不能称作完整文章包备份。
- 浏览器逻辑包、本地磁盘目录与服务器数据卷是不同实现；浏览器模式不自动写回源文件旁边，文章 ZIP 也不等于整站备份。
- 旧文、配置与未知 frontmatter 保留；不为升级清库、降级或静默覆盖。目录原件不自动移动，外链不自动下载。
- Docker 为自托管服务器工作区，不做自动同步。通用插件、桌面端启用、公共图床、官方云、计费和实时协作不在当前范围。
- P1、P2a 原型与本轮浏览器接入均已按用户要求本地提交。推送、部署、镜像和 tag / Release 仍需对应授权。
