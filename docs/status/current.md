## 当前产品与停止线

- 已提供 Web 写作、主题预览、本地草稿 / 文件夹、Markdown 单文件进出及公众号复制，职责见 [产品范围](../product-scope.md)。P1 本地完成不等于已上线。
- 图片资源的磁盘目录、浏览器逻辑包与服务器数据卷是不同实现；浏览器模式不承诺自动写回源文件旁边。未来文章 ZIP 不等于整站备份。
- Docker “云端”为自托管服务器工作区，首轮不做本地工作区自动同步。账号关闭即共享工作区，用户隔离必须由后端会话和每次 IO 鉴权实现。
- 旧文章、配置、未知 frontmatter 和上游来源保留；P2 存储升级须明确迁移与恢复，不沿用 P1 的“无 schema 变化”约束掩盖必要升级。
- 通用插件、桌面端启用、公共图床、官方托管云、计费、实时协作和批量文章归档仍不在当前范围。
- P1 与本轮 P2a 原型均按授权本地提交，用户仍明确暂不推送或发布。推送、部署、镜像和 tag / Release 继续按对应授权执行。
