## 当前产品与停止线

- 产品已提供 Web 写作、主题预览、本地草稿 / 文件夹、单 Markdown 进出及公众号复制。模块职责与新的两种部署方向见 [产品范围](../product-scope.md)。
- 图片资源的磁盘目录、浏览器逻辑包和服务器数据卷是不同物理实现；浏览器模式不承诺自动写回源文件旁边。默认 ZIP 不等于完整站点备份。
- Docker “云端”为自托管服务器存储，首轮不做本地工作区自动同步。账号关闭即共享工作区；用户隔离必须由后端会话与每次 IO 鉴权实现。
- 旧文章、配置、未知 frontmatter 和上游来源保留；未来二进制存储需要正式迁移说明，不为保持“零 schema 变化”的旧口径掩盖实际升级。
- 通用插件、桌面端启用、公共图床、官方托管云、计费、实时协作及批量文章归档不在本轮范围；[插件规划](../planning/plugin-system.md) 不作为当前功能依赖。
- 本轮无远程写入授权。后续推送可能触发 Vercel 线上变更，提交、推送、镜像发布、部署及 tag / Release 分别遵循对应授权。
