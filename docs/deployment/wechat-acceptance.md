# 公众号验收步骤

本流程用于 Vercel 验收站点，不代表正式发布。使用 [合成样例](wechat-acceptance-sample.md)，不要上传真实文章或凭据。每轮结果记入当轮 `docs/records/`，未执行填“未验证”。

## 官方开发规范

公众号编辑器适配以微信官方的 [订阅号编辑器开发规范](https://developers.weixin.qq.com/doc/subscription/guide/product/plugin_spec.html) 为参考，使用 `subscription` 文档入口，不使用服务号的 `service` 入口。排版、复制 HTML、结构检测和手机明暗效果的开发与验收应核对该规范。

行高问题对应 [1.3 line-height](https://developers.weixin.qq.com/doc/subscription/guide/product/plugin_spec.html#_1-3-line-height)。结构检测、暗色转换及辅助调试工具的仓库与使用方法统一维护在 [公众号编辑器参考渠道](../development/wechat-editor-references.md)。本地测试、公开检测器和浏览器检查不代表真实公众号验收通过。

## 开始条件

- 记录站点完整 URL、部署提交 SHA、浏览器及版本、操作系统、主题、表格换行及链接转脚注开关。
- 必须从已确认的验收域名打开编辑器。localhost 图片不能用于验证公众号远程转存。
- 用无登录状态请求 `/pwa/icon-192.png`、`/images/writing.svg`、`/images/mac-sign.svg`；检查 HTTP 200、图片 Content-Type 和实际图像内容，不能是登录页、验证页或 SPA HTML。
- 核对部署保护与访问范围；不要把 Vercel bypass token 写入文章或图片 URL。桌面可访问后，仍须从实际使用网络及手机验证。
- 使用独立浏览器配置或临时数据；保留用户原有草稿。每个域名拥有独立的浏览器存储，本轮不实现导入导出，也不承诺跨域名迁移。

## 用户操作（每个主题一轮）

1. 在验收站点新建测试文章，把 [样例源文件](wechat-acceptance-sample.md) 的完整 Markdown 文本粘到源码编辑区，确认尾部 `RI-END` 出现。首轮用默认主题，次轮选一个有背景的主题，记录准确名称。代码栏圆点单独用主题设计器中开启“Mac 风格控制栏”的自定义主题检查；未开启不能记为圆点通过。
2. 等待图片、公式和 Mermaid 显示，点击“复制到公众号”。在公众号后台新建测试图文，粘贴到正文，等待图片处理结束；逐项检查下表，不使用“复制 HTML”的源码文本替代富文本粘贴。
3. 保存为草稿，离开编辑页面后重新打开同一草稿，再逐项检查。记录图片是否已转存、公式和图表是否丢失、表格是否变形；不要只观察保存成功提示。
4. 打开公众号预览，在手机上检查明暗显示与窄屏效果；需要发送预览时由账号所有者选择自己的接收账号。此步骤不群发、不发布文章。
5. 回报“域名／提交、浏览器、主题、粘贴后、重开后、手机明暗、失败项”。失败时只截合成正文，避免截图带入账号资料；未做的步骤直接写“未验证”。

## 分项判据

| 编号      | 内容                                       | 粘贴后                   | 保存重开后                     | 手机／明暗           |
| --------- | ------------------------------------------ | ------------------------ | ------------------------------ | -------------------- |
| A         | 中文、列表、勾选、引用、行内代码、文章尾部 | 无遗漏，结构完整         | 无新增丢失                     | 文字与背景可辨       |
| B-PNG     | 本站 PNG 图标                              | 图像正确，转存无报错     | 仍显示，记录实际转存情况       | 清晰、不溢出         |
| B-SVG     | 本站 SVG 插画                              | 单独记录格式兼容性       | 无破图、无空白                 | 比例正常             |
| C         | 行内公式、分式根号、矩阵积分               | 符号与基线完整           | 转换后的公式仍在，无源码泄漏   | 清晰、完整、颜色可辨 |
| D         | 短表格与宽表格                             | 边框、对齐、换行符合选择 | 行列内容和样式保留             | 无遮盖、无不可读截断 |
| E-Code    | 代码与代码栏圆点                           | 空格、换行、特殊字符完整 | 圆点单独判定，不以正文成功代替 | 长行可读             |
| E-Mermaid | 流程图                                     | 图像与所有文字完整       | 无破图、无空白                 | 清晰且可读           |

表格换行开关两种状态都要覆盖；若首轮发现问题，只重测相关样例并记录触发条件，不抹去失败结果。普通图片、公式内联 SVG、图表 PNG 数据和代码栏 SVG 链接的传输形式不同，不能互相替代证据。

## 本地辅助检查

浏览器 smoke 检查默认外部请求、图片加载、主题切换、草稿刷新恢复、两种复制、帮助与许可页面。确认复制的 HTML 图片地址指向当前源；确认公式／图表转换有内容，复制失败有可见提示。

本地原生剪贴板写入、复制 HTML 字符串、公众号首次粘贴、公众号保存重开和手机效果分别记录。前两项成功不能推导后三项成功。公网匿名图片检查也不能证明公众号已成功转存。
