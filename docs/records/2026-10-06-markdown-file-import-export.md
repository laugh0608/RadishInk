## 实现

- Web 两种文件栏及触屏“更多功能”提供单文件导入和当前文章导出；严格 UTF-8 / BOM / 5 MiB、空文件、同名编号及文本资源提示。
- 默认浏览器存储复用既有历史记录库，目录工作区复用文件适配器；导入的完整源文存入现有 Markdown 字段，恢复与编辑显示正文，保存时合回未知元数据。
- 导出直接取得最新正文、标题、主题和原元数据，不等待自动保存，不序列化设置或自定义 CSS。下载仅报告发起，并释放临时 URL。
- 修复顶层元数据误匹配嵌套字段、正文开头空白丢失、历史库吞掉写入错误，以及列表变化回滚正在输入内容的问题。
- 保存队列在同一适配器的多个 hook 实例间共享；文件打开前保存失败停止切换；操作绑定文章和实际目录身份，迟到结果不能进入新工作区。存储模式切换在候选初始化和旧稿保存成功后才释放旧适配器。
- 移动端复用入口时发现通用 `.btn-secondary` 被全局触屏样式隐藏，改用专用按钮样式后通过实际浏览器复测。
