## 命名决策

以 Radish 的版本治理文档和实际 Docker 工作流为主要来源，并交叉阅读 RadishFlow / RadishAxiom 版本专题及 RadishMind 发布配置：

- 新 tag：`vYY.M.RELEASE-(dev|test|release)`，可选 `.DDXX` 构建扩展。
- Docker 固定标签及 OCI 版本字段原样使用完整 Git tag。
- 浮动别名遵循 Radish：`dev-latest`、`test-latest`、`release-latest`；仅正式轨道另更新 `latest`。
- 引入只读元数据脚本及负向测试，停用 Docker 模板复用同一脚本；Compose 要求显式版本，不再默认拉取上游镜像。
- 首次产品版本、源码同步和真正发布仍需独立准备，本次没有分配版本或创建 tag。
