## 实现与取舍

1. **移除图床 / AI 功能链路。** 覆盖常规顶栏、浮动栏、编辑工具、选区改写、评分侧栏和设置事件；删除无剩余调用者的 Web 专用服务、设置界面、状态与对应专用测试。新增负向测试证明旧启用配置 / 事件不能复活入口或请求。旧 `imageHostConfig`、`imageHostConfigs`、`wemd-ai-config` 原值保留；未执行配置迁移或清理。
2. **图片过渡行为。** 图片文件粘贴 / 拖入提示“文章图片保存功能尚未提供”，不插入占位、替换选区或上传。普通文本粘贴与 Markdown 外链继续可用；“图片链接”仅插入链接语法。外链预览请求与已停用的上传请求分别检查。
3. **统一文件菜单。** `MarkdownTransferProvider` 在存储上下文内常驻文件输入与单份传输 hook，顶栏右侧、浮动栏及移动端“更多功能”→“文件”共用命令和忙碌状态。菜单关闭不卸载文件读取，导入期间禁止重复导入和导出；存储未就绪仍允许抢救导出。侧栏移除导入 / 导出按钮与常驻说明，格式与资源限制移至菜单和帮助。
4. **渐进收纳。** `Toolbar` 使用同一组命令定义，`useToolbarOverflow` 测量独立的非交互行，按优先级保留可容纳工具，仅将其余工具放入左侧“更多”。预留按钮、间距和内边距；监听容器、按钮尺寸、字体就绪与窗口变化，无 `ResizeObserver` 时以可清理的逐帧测量降级。焦点所在命令被收纳时回到可见入口。
5. **浮层与操作。** `ActionMenu` / `TooltipLayer` 通过 Portal 脱离面板裁切，复用并扩展 `floatingPanelBox`；按内容实际尺寸定位并处理视口碰撞。编辑菜单起点对齐，文件菜单末端对齐，提示居中；打开时跟踪位置，关闭后停止。菜单支持方向键、Home / End、子页返回、Esc、焦点返回和触屏点击；触屏工具和菜单项至少 44px。

行为契约分别维护在 [界面专题](../planning/editor-interface.md)、[Markdown 进出](../planning/markdown-file-import-export.md) 和 [外部服务说明](../development/web-brand-and-services.md)。本轮没有提前提供 ZIP、文章图片持久化、后端或账号。

## 检查中发现的问题与处理

- 文件选择器 `cancel` 不在当前 React 输入属性类型中，改为常驻输入的原生监听；没有绕过类型检查。
- 截图发现短 Tooltip 按固定宽度计算后远离按钮，改为按实际宽度居中；菜单同时补齐实际高度和对齐方式，重新截图验证。
- 新测试曾将 Testing Library 的 role 查询写成正则，修正查询后通过；浏览器分栏脚本原用不支持的 Home / End，改用现有左右方向键和真实拖动，未修改分栏契约。
- CLI 对脚本中的原生文件选择器会提前返回控制，手动处理残留状态与脚本续跑一度竞态；关闭该测试会话后独立复核已下载文件、刷新恢复和请求计数，未把工具竞态当作产品失败。
- 复制检查最初把 HTML 的 Mermaid 源结构误当作预览 SVG，并固定等待普通成功文案；核对原复制契约后按实际输出和公式保真提示重新验证，未修改复制实现。
- 沙箱阻止本地端口监听和 npm 缓存 / 代理访问时，使用工具审批运行已授权的开发服务与浏览器工具；未安装新依赖或修改全局配置。
