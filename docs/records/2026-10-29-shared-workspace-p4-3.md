## 实现与边界

- 部署显式选择 `accounts` / `shared`，关闭登录方法不触发共享降级。共享模式的 HTTP / Web 使用固定所有者，持续显示无用户隔离与读写删除提示，不提供登录、退出或账号绑定。
- 共享写入保留 Origin / CSRF；所有共享文章请求绑定部署 ID 和 epoch，worker 重复验证固定归属与 epoch。共享 Cookie 不是身份凭据，签名绑定部署、epoch、进程密钥，有效期 12 小时；重启或恢复后需重新连接。
- 双向归属转换先备份，在空目标的隔离暂存副本中执行，原卷不改模式与 epoch。要求有效接收者，拒绝多用户转共享；保留文章 ID、内容字节、原图、revision、墓碑、回执和账号凭据 / 绑定，仅转换协议归属及用量。
- 成功后撤销旧会话和 OIDC 尝试并轮换 epoch；失败目标保留保护标记。旧页面不能把旧稿重放到恢复 / 转换后的工作区。身份失效沿用既有隐私清理边界，维护前必须先保存或导出；断网但身份未失效时才保留现有抢救流程。
- 未更改 schema 迁移定义、存储键、依赖、旧上传路由或发布工作流。操作与协议的详细来源为 [共享工作区](../deployment/shared-workspace.md)。
