# v26.10.2-dev 源码预发布

日期：2026-10-25。本页随候选提交保存发布范围、授权和验证结果；远程 PR、合并提交、tag 与 Release 的最终状态以 GitHub 实际结果为准，不预写发布成功。

## 授权与目标

用户明确将 P1 / P2 验收延后至有时间或开发稳定后，要求先完成阶段 PR、发布 `v26.10.2-dev` 及同名 Release。用户所说的 `master` 按稳定主线理解；远程已核对只有 `main` / `dev`，默认分支为 `main`，因此执行 `dev → main`，不新建或改名主分支。

- 产品版本：根 `version.json` 的 `26.10.2` / `dev`；Web 侧栏与关于弹窗共用该来源，不批量修改继承的 package 版本。
- PR：等待当前 head 的 `Candidate Quality` 成功，以 merge commit 合入 `main`；随后将 `main` 快进回流 `dev`。
- tag：在主线合并提交创建新的附注 tag `v26.10.2-dev`，不覆盖或移动已有标签。
- Release：显式授权的源码 Pre-release，非 Latest；只复用已经推送的同名 tag，附件仅 GitHub 自动提供的源码 ZIP / tar.gz。
- Docker 与桌面发布工作流继续停用；P3 / P4 后端和账号没有随此版本启用。Vercel 沿用现有 dev 自动部署及内容去重配置，推送可能更新现有站点，不修改环境、域名或通知设置。

## 版本内容

- **写作界面**：统一文件菜单、工具栏按宽度收纳、浮层与提示修复；移除 Web 图床 / AI 入口及调用链，保留旧配置数据。
- **文章工作区**：浏览器与目录文章包，旧 JSON 合并恢复、备份升级、冲突副本、整包复制 / 移动 / 删除和目录权限恢复；取消自动淘汰旧文章。
- **图片与可移植性**：粘贴 / 选择图片后保存原字节、相对引用和资源预览；默认 ZIP 下载 / 回导、Markdown 仅文本抢救入口；最新快照、缺图、非法包及失败边界检查。
- **安全更新**：PWA 新版就绪时提示，保存并检查其他页面后切换；失败保留输入；历史版本迁入与后续离线升级分别验证。
- **浏览器兼容**：Safari / Firefox 的图片、ZIP、刷新与安全更新；修复 Mermaid 暗色标签和箭头的可读性，保留显式图表配色。

## 数据、来源与恢复边界

浏览器文章使用 `wemd-history` v3；v2 升级前需下载备份并确认，超过 30 篇的旧文保留。目录旧单文件原位保留，新文章包为 `index.md` + `asset/`；未知 frontmatter 和原图字节保留。升级前 JSON 不包含后来增加的资源，纯 Markdown 也不含图片；迁移或恢复前应备份完整文章 ZIP / 目录，详见 [存储契约](../development/article-storage-contract.md)。

相对上一开发版，ZIP 增加锁定的 `fflate@0.8.3`，采用包内 MIT 原文并由现有声明生成器分发；WeMD 历史、根许可、兼容标识及旧配置保留。当前应用不新增统计、默认上传或 AI 请求；文章既有外链图片仍会访问其来源，公网注入脚本与应用请求须分开判断。

源码对照与上一版本为 `v26.10.1-dev` / `784e4a0`。不能把切回旧版本代码当作 v3 数据降级方案；出现回归时保留原数据与备份，按 [部署恢复](../deployment/vercel.md#失败与回退) 评估前向修复或已验证部署，不清库、不移动已发布 tag。PWA 更新失败继续保留输入，历史首次迁入按 [升级步骤](../development/pwa-updates.md) 保存并关闭全部旧页面后重开。
